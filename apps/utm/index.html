01 About

Run real operating systems on your iPhone or iPad. UTM is an open-source (Apache-2.0) virtualization and emulation platform built on QEMU, capable of running Windows, Linux, classic Mac OS and dozens of other systems alongside your apps. Highlights: - QEMU v10.0.2 backend with support for dozens of CPU architectures (x86_64, ARM64, RISC-V, PowerPC and more) - Improved machine wizard with well-tested configurations such as Windows, Ubuntu, RISC-V64 Ubuntu, classic Mac OS 8.x/9.x and Windows 95/98 - Custom keyboard shortcuts (e.g. Ctrl+Alt+Del) sent directly to the VM from the Keyboard menu - App Intents automation with the Shortcuts app - Liquid Glass design on iOS 26 - Import and export .utm virtual machine bundles via the Files app - No jailbreak required; highest performance with JIT workarounds on supported iOS versions

## Highlights
* **QEMU v10.0.2**: The backend has been updated to the latest upstream QEMU which brings with it a variety of bug fixes and performance improvements.
* **Liquid Glass**: UTM adopts the Liquid Glass design on *OS 26.
* **App Intents**: New support for automation with Shortcuts.
* **Keyboard Shortcuts**: Define custom key combinations (such as Ctrl+Alt+Del) that can be sent to the VM from the new Keyboard menu.
* **Improved Wizard**: Simplify the creation of emulated machines by selecting from a list of well-supported configurations. The updated wizard can create more working configurations such as RISC-V64 Ubuntu, classic Mac OS 8.x/9.x, and Windows 95/98.
