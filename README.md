# YouProEXTRA — AltStore Repository

AltStore/ESign/Feather/SideStore/LiveContainer source for all [YouProEXTRA](https://github.com/mrdrvt99/YouProEXTRA) Tweaks. no need to fork GitHub repos or find your own decrypted IPA files!

## How to Add This Source

1. Open **AltStore/ESign/Feather/SideStore/LiveContainer** on your device
2. Navigate to **Sources** or **Repos**
3. Tap **+** and paste the URL of the tweak you want below:
### YTLite
```
https://raw.githubusercontent.com/mrdrvt99/Altstore-Repository/main/ytlite.json
```
### YTKillerPlus
```
https://raw.githubusercontent.com/mrdrvt99/Altstore-Repository/main/ytkp.json
```
### YouPro
```
https://raw.githubusercontent.com/mrdrvt99/Altstore-Repository/main/youpro.json
```
### YouMod
```
https://raw.githubusercontent.com/mrdrvt99/Altstore-Repository/main/youmod.json
```
### YTKACE
```
https://raw.githubusercontent.com/mrdrvt99/Altstore-Repository/main/ytkace.json
```
### YTMusicUltimate
```
https://raw.githubusercontent.com/mrdrvt99/Altstore-Repository/main/ytmusic.json
```
### Esign users can also use this combined link below
```
https://raw.githubusercontent.com/mrdrvt99/Altstore-Repository/main/apps.json
```
4. YouTube will appear under Browse — tap **Get** to install
> **Note:** You must have a signing method set up (AltStore, SideStore, Feather, Signulous, etc.) to install the IPA.
> **Note:** if you got a warning about missing permissions/entitlements just install anyway.

Each app has a unique source identifier so your sideloader tracks them separately. you can only have one installed at a time.

## ⚠️ Note for Existing Users

> **Important:** If you already have one of these tweaks installed (from a direct IPA, a different source, or a previous sideload), **do not just add this source and tap Update**.
>
> Because all four apps share the same real bundle ID (`com.google.ios.youtube`), your sideloader cannot tell which source entry belongs to your installed app. Tapping **Update** may install the wrong tweak.
>
> **Correct steps for existing users:**
> 1. Back up any app data if needed
> 2. Delete the currently installed YouTube tweak from your device
> 3. Add this source URL to your sideloader
> 4. Install the desired tweak fresh from the source
>
> Once installed from this source, future updates will work correctly and automatically.
