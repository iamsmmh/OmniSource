📲 Installation Guide

 AltStore

1. Open this README on your iOS device.
2. Tap Add to AltStore⁠￼.
3. Allow AltStore to open.
4. Confirm the source import.
5. Refresh the source.

 SideStore

1. Open this README on your iOS device.
2. Tap Add to SideStore⁠￼.
3. Allow SideStore to open.
4. Confirm the source import.
5. Refresh the source.

Manual Import

 Feather⁠￼

1. Open Feather⁠￼.
2. Open Sources.
3. Select Add Source.
4. Paste the desired feed URL.
5. Save and refresh.

 LiveContainer⁠￼

1. Open LiveContainer⁠￼.
2. Open its source/repository section.
3. Add the desired OmniSource feed URL.
4. Save and refresh.

 E-Sign⁠￼

1. Open E-Sign⁠￼.
2. Open the repository/source section.
3. Add the desired OmniSource feed URL.
4. Save and refresh.

 Signulous⁠￼

1. Open Signulous⁠￼.
2. Open the available source/repository section.
3. Add the desired OmniSource feed URL where supported.
4. Save and refresh.

Recommended: Use the OmniSource Master Feed⁠￼ for the complete collection.

⚙️ GitHub Actions

OmniSource uses GitHub Actions⁠￼ to automate feed processing, updates, validation, and workflow cleanup.

Workflow	Purpose
update.yml⁠￼	Automated feed/update workflow
updatex.yml⁠￼	Additional update automation
lint-action.yml⁠￼	Workflow validation and linting
delete-old-workflows-run.yml⁠￼	Workflow-run cleanup

Automation Pipeline

Upstream Releases
       ↓
GitHub APIs
       ↓
GitHub Actions
       ↓
Process / Update
       ↓
Manifest Generation
       ↓
Validation
       ↓
GitHub Pages
       ↓
OmniSource Feeds
