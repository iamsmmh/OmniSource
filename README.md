## 📲 Installation
### Automatic Import
**AltStore**
- Tap the AltStore button above
- Approve source import
- Refresh sources
**SideStore**
- Tap the SideStore button above
- Approve source import
- Refresh sources
### Manual Import
For Feather, LiveContainer, ESign, Signulous, or manual setup:
1. Copy the desired feed URL
2. Open your source/repository manager
3. Add a new source
4. Paste the feed URL
5. Refresh sources
> [!TIP]
> Use the **OmniSource Master Feed** for access to all available applications from a single source.
---
> [!WARNING]
> ### YouTube Bundle Identifier Conflicts
>
> Most modified YouTube applications use:
>
> ```text
> com.google.ios.youtube
> ```
>
> Completely uninstall any existing YouTube variant before installing another variant to prevent update, signing, or bundle identifier conflicts.
---
> [!NOTE]
> Installation and signing behavior may vary depending on the sideloading client and signing environment being used.
