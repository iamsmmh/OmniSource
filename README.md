OmniSource —  Repository
AltStore/ESign/Feather/SideStore/LiveContainer source for all tweaks in OmniSource. No need to fork GitHub repos or find your own decrypted IPA files!
How to Add This Source
 * Open AltStore/ESign/Feather/SideStore/LiveContainer on your device
 * Navigate to Sources or Repos
 * Tap + and paste the URL of the tweak you want below:

Each app has a unique source identifier so your sideloader tracks them separately.
⚠️ Note for Existing Users
> Important: If you already have one of these tweaks installed (from a direct IPA, a different source, or a previous sideload), do not just add this source and tap Update.
> If multiple apps share the same bundle ID (for example, YouTube tweaks sharing com.google.ios.youtube), your sideloader cannot tell which source entry belongs to your installed app. Tapping Update may install the wrong tweak.
> Correct steps for existing users:
>  * Back up any app data if needed
>  * Delete the currently installed app/tweak from your device
>  * Add this source URL to your sideloader
>  * Install the desired tweak fresh from the source
> Once installed from this source, future updates will work correctly and automatically.
